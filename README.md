# NEON TETRIS 🎮

ネオン・サイバーパンク調のテトリス。8ビット・チップチューンBGM付き。
**APIキーなしで今すぐ遊べます。**

## 遊び方
`index.html` をダブルクリックしてブラウザで開き、**START** を押すだけ。
（START を押した瞬間に音が有効になります＝ブラウザの自動再生制限のため）

### 操作
| キー | 動作 |
|---|---|
| ← → | 移動 |
| ↑ / X | 右回転 |
| Z | 左回転 |
| ↓ | ソフトドロップ |
| Space | ハードドロップ |
| C | ホールド |
| P | ポーズ |

右側のパネルで **MUSIC / SFX** のON/OFFを切り替えられます。

## 機能
- 7種テトロミノ・7-bag方式のランダム生成
- ゴースト表示 / ホールド / ネクスト
- ライン消し（1〜4ライン）、レベルアップで落下速度上昇
- スコア・ライン数・レベル・ハイスコア（ブラウザに保存）
- ネオングロー描画＋8bit BGM（Korobeiniki）とSFXをコードで生成

## （任意）OpenAIで背景画像を生成する
背景をAI生成画像にしたい場合は、付属の `generate_images.py` を**あなたの端末で**実行します。
APIキーは環境変数から読み込むだけで、スクリプトやゲームには保存されません。

```bash
export OPENAI_API_KEY="sk-..."   # Windows: $env:OPENAI_API_KEY="sk-..."
pip install openai
python generate_images.py
```

実行すると `images/background.png` が作られ、次に `index.html` を開いたとき
自動で背景に反映されます。画像が無くてもゲームはそのまま動きます。
